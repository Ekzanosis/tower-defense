# Категории сооружений — утверждено 2026-11-05

Категории используются для сортировки экипировки и определения применимости бонусов. Категория — свойство сооружения, а не класса героя. Игрок может комбинировать сооружения любых категорий.

| Категория | Примеры |
| --- | --- |
| Магические | Магические снаряды, огненные башни, лучи, молнии |
| Механические | Баллисты, пушки, вращающиеся лезвия, баррикады |
| Ауры | Замедление, электрический урон, ослабление, ярость |
| Ловушки | Мины, огненные, ледяные, газовые ловушки |
| Призыв | Призванные лучники, маги, воины, големы |

## Примеры бонусов экипировки (не утверждены как баланс)
- +15% урона магических сооружений
- +20% здоровья механических сооружений
- +10% радиуса аур
- +2 заряда ловушкам
- +1 к количеству призываемых существ

Пять категорий утверждены. Значения бонусов и конкретные сооружения ещё обсуждаются.
